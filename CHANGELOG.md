# Change Log

All notable changes to the "etmlm-support" extension will be documented in this file.

## [1.0.0] - 2026-09-02

### Added
- Initial release
- Syntax highlighting for `.etmlm` files (classic TTML tags, custom ETMLM tags, attributes, strings, operators, lyric text)
- Custom file icon theme ("ETMLM Icon Pack") for `.etmlm` files
- Language configuration: auto-closing tags/quotes, bracket matching, code folding, smart indentation
